# 🎯 QuizIn - Interactive Web Quiz Platform

**QuizIn** adalah aplikasi web kuis interaktif berbasis *pure client-side* (tanpa backend) yang terinspirasi dari Quizizz. Project ini dikembangkan sebagai bagian dari **Capstone Project IBM Bob** menggunakan metode *vibe coding* berstruktur 3 Layer.

---

## 🚀 Fitur Utama

- **Dual User Roles:**
  - **Creator Mode:** Membuat kuis baru, menambahkan soal pilihan ganda, menentukan kunci jawaban, dan mengatur batas waktu.
  - **Player Mode:** Mengikuti kuis interaktif dengan indikator timer *real-time* dan *feedback* jawaban instan (Hijau/Merah).
- **Client-Side State Management:** Penyimpanan data kuis secara lokal menggunakan `localStorage` browser.
- **Import & Export JSON:** Fitur untuk mengunduh dan mengunggah data kuis dalam format JSON.
- **Responsive & Modern UI:** Desain antarmuka tema *Modern Blue Slate* dengan sentuhan *Glassmorphism*.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5:** Struktur semantik aplikasi Single-Page Application (SPA).
- **CSS3:** Styling kustom (Flexbox, CSS Grid, Glassmorphism, animations) tanpa framework eksternal.
- **Vanilla JavaScript:** Logika interaktif kuis, timer countdown, feedback visual, dan pengolahan `localStorage`.
- **IBM Bob AI:** Tools pengembang utama untuk eksekusi *vibe coding*.
